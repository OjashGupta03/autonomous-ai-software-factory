# 15 - API Reference

Full interactive documentation is auto-generated by FastAPI at `/docs` (Swagger UI) and
`/redoc` once the backend is running - this page is a map, not a substitute. All routes
below are mounted under `/api/v1` (`Settings.API_V1_PREFIX`) and, except `/auth/*`,
require `Authorization: Bearer <token>`.

## Auth

| Method | Path | Notes |
|---|---|---|
| POST | `/auth/register` | Create a user. |
| POST | `/auth/login` | OAuth2 password form (`username`=email, `password`) - not a JSON body, so the generated `/docs` "Authorize" button works out of the box. |
| GET | `/auth/me` | Current user from the bearer token. |

## Projects

| Method | Path | Notes |
|---|---|---|
| POST | `/projects` | Create a project from a name + natural-language requirement. |
| GET | `/projects` | List the caller's own projects, with rolled-up task/cost summaries. |
| GET | `/projects/{project_id}` | 404s (not 403) if the project isn't yours - existence isn't confirmed either way. |
| POST | `/projects/{project_id}/start` | Enqueues the orchestrator run. Returns `202` immediately; watch `/events` for progress. |

## Tasks

| Method | Path | Notes |
|---|---|---|
| GET | `/projects/{project_id}/tasks` | Flat list, each with `depends_on`. |
| GET | `/projects/{project_id}/tasks/graph` | DAG-shaped response for the frontend's graph view. |
| GET | `/projects/{project_id}/tasks/{task_id}` | Full detail: files modified, latest error, tokens, cost. |

## Agents

| Method | Path | Notes |
|---|---|---|
| GET | `/agents` | The active agent catalog. |
| GET | `/projects/{project_id}/agent-runs` | Every agent execution for the project, newest first. |

## Files & artifacts

| Method | Path | Notes |
|---|---|---|
| GET | `/projects/{project_id}/files` | Latest version of every file (metadata only, no content). |
| GET | `/projects/{project_id}/files/content?path=` | Full content of one file's latest version. |
| GET | `/projects/{project_id}/files/diff?path=&from_version=&to_version=` | Unified diff between two versions. |
| GET | `/projects/{project_id}/artifacts` | All artifact references for the project. |

## Tests

| Method | Path | Notes |
|---|---|---|
| GET | `/projects/{project_id}/tests` | Test run history with per-test results. |
| POST | `/projects/{project_id}/tests/rerun` | Manually re-trigger the orchestrator run (routes to integration tests if the build phase is already done). |

## Approvals

| Method | Path | Notes |
|---|---|---|
| GET | `/projects/{project_id}/approvals` | Pending approvals only. |
| POST | `/projects/{project_id}/approvals/{approval_id}/decide` | `{"decision": "approved" \| "rejected" \| "modified", "note": "..."}`. |

## Metrics

| Method | Path | Notes |
|---|---|---|
| GET | `/projects/{project_id}/metrics` | LLM calls, tokens, cost, retries, cache hits, by-model breakdown. |
| GET | `/projects/{project_id}/metrics/comparison` | Naive-vs-optimized estimate - see [07-token-optimization.md](07-token-optimization.md). |
| GET | `/projects/{project_id}/metrics/token-usage` | Raw per-call rows. |

## Live events

| Method | Path | Notes |
|---|---|---|
| GET | `/projects/{project_id}/events` | Server-Sent Events. Replays the last 100 events on connect, then streams live via Redis pub/sub. See [16-frontend.md](16-frontend.md). |

This table was generated by walking the actual router files (`app/api/v1/*.py`) rather
than written from memory, specifically to avoid the doc drifting from the implementation.
